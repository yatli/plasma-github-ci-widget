## Description

A compact Plasma 6 panel widget that shows the live build status of a GitHub
Actions workflow as a shields-style badge.

- Live `[ build | passing ]` badge (green / red / yellow / grey states)
- A strip of dots summarizing the most recent runs
- Click to expand a popup listing the last 10 runs, each linking to GitHub
- Auto-detects the default branch (or set one manually)
- Configurable repository, workflow, branch, label, and refresh interval
- Optional GitHub token for private repositories

Right-click the widget → **Configure** to set your repository and workflow.
